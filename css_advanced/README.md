# CSS Advanced

## Description
This project focuses on the CSS and styling of a webpage based on a Figma designer file.
It follows the HTML Advanced project where the HTML structure was built.

## Designer File
The designer file is available on [Figma](https://www.figma.com).

## Objectives
- Implement CSS styling from a Figma designer file
- Apply colors, fonts, spacing and layout using CSS
- Match the design as closely as possible

## Requirements
- All files should end with a new line
- A README.md file at the root of the folder is mandatory
- No external CSS framework allowed
- No JavaScript allowed
