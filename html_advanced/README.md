# HTML Advanced

## Description
In this project, we implement a webpage from a designer file using pure HTML semantic structure only - no CSS, no style.

## Objectives
- Implement a webpage from a Figma designer file
- Focus on HTML structure only
- Use pure HTML semantic tags
- No CSS or styling

## Requirements
- All files should end with a new line
- A README.md file at the root of the folder is mandatory
- No external libraries allowed
- No CSS, no style - just pure HTML semantic
